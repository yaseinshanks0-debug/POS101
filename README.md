# QuickPOS — نظام نقطة بيع (Android/Kotlin)

تطبيق POS للهواتف الأندرويد باللغة العربية، مبني بـ **Kotlin + Jetpack Compose + Room + CameraX + ML Kit**، يعمل **بالكامل دون اتصال** وبدون أي API أو مفاتيح.

## المميزات المطبقة

- **مسح الباركود بالكاميرا** (CameraX + ML Kit): أي صنف ممسوح يُضاف مباشرة للفاتورة المفتوحة.
- **فواتير متعددة في آن واحد**: افتح أكثر من فاتورة، بدّل بينها بألسنة، وأتم كل واحدة مستقلة.
- **تسعير مربوط بالدولار**: أسعار المنتجات مخزنة بالدولار؛ عند تعديل سعر الصرف في الإعدادات **تتحدث كل الأسعار والأرباح بالجنيه السوداني تلقائياً** لكل المنتجات والمبيعات.
- **تقارير مفصلة** (يوم/أسبوع/شهر/الكل): إجمالي المبيعات، الخصومات، صافي المبيعات، تكلفة البضاعة، إجمالي الربح، المصروفات، **صافي الربح**، متوسط الفاتورة، والأكثر مبيعاً.
- **مصروفات** قابلة للتصنيف والحذف.
- **توصيات عروض ذكية**: النظام يحلل البطيء الحركة والمخزون المكدّس ويقترح نسب خصم.
- **أكواد خصم (كوبونات)**: نسبة أو مبلغ ثابت، **بعدد استخدام محدد** و**نافذة زمنية**، تُستهلك تلقائياً عند كل فاتورة.
- **مخزون منخفض** مع تنبيهات في الرئيسية.
- **نسخ احتياطي محلي**: تصدير ملف JSON ومشاركته، ثم استيراده في أي وقت.
- **طرق دفع متعددة**: كاش / تحويل (مع رقم مرجع وصورة إشعار) / دَين مع تتبّع أرصدة العملاء.
- **صور المنتجات**: إرفاق صورة لكل منتج تظهر في البيع والمنتجات.
- **بحث موحّد**: في صفحة البيع ابحث عن الصنف بالاسم أو الباركود مع صور.
- **مشاركة الفاتورة**: زر مشاركة في تفاصيل الفاتورة لإرسالها (واتساب/بريد...) كنص.
- **حسابات متعددة**: تسجيل دخول، أدوار (مدير/كاشير)، وإدارة مستخدمين، مع حماية كلمات المرور (SHA-256).
- **عملاء**: حفظ العملاء وارصدة الديون مع إدارة من الصفحة الرئيسية.

## هيكل المشروع

```
app/src/main/java/com/quickpos/app/
├── QuickPosApp.kt            # نقطة البداية + حقن بسيط للـ repositories (يعمل دون اتصال)
├── MainActivity.kt
├── data/
│   ├── local/                 # Room: الكيانات (منتجات/فواتير/عملاء/مستخدمون) + DAOs + قاعدة البيانات
│   ├── repository/            # العملة، الكتالوج، البيع (الفواتير المتعددة)، التقارير، المستخدمون
│   └── remote/BackupManager   # نسخ احتياطي JSON محلي
└── ui/
    ├── navigation/            # التنقل + الشريط السفلي
    ├── components/            # مكوّنات مشتركة (حقول، بطاقات، طرق الدفع، مشاركة التحويل)
    └── screens/               # الدخول، البيع، المنتجات، الفواتير، التقارير، المصروفات، الكوبونات، الإعدادات، المستخدمون
```

## تسجيل الدخول

- عند أول تشغيل يُنشأ مستخدم افتراضي: **اسم المستخدم `admin` وكلمة المرور `admin`** (غيّره فوراً).
- من **الإعدادات ← المستخدمون** يمكن إضافة كاشير/مدير وحذفهم (لا يمكن حذف آخر مدير).
- زر **تسجيل الخروج** في الإعدادات يعيدك لشاشة الدخول.

## خطوات التشغيل

1. ثبّت **Android Studio** (يتضمّن JDK وAndroid SDK).
2. افتح المجلد `Default Project` كمشروع (File → Open).
3. عند فتحه لأول مرة سيطلب تنزيل Gradle 8.9 تلقائياً (جارٍ تكوينه في `gradle/wrapper`).
4. تأكد من تثبيت **Android SDK 34** داخل Android Studio (SDK Manager) وموافقة Android Studio على إنشاء `local.properties`.
5. شغّل على جهاز فعلي أو محاكي بأندرويد 8.0+ (minSdk 26).

> ماسح الباركود يحتاج كاميرا خلفية — على المحاكي يمكنك استخدام شاشة البحث اليدوية.

## النسخ الاحتياطي

- **محلي وبدون إنترنت**: من **الإعدادات ← النسخ الاحتياطي المحلي** صدّر ملف JSON (سيفتح لك نافذة المشاركة لحفظه)، واستورده أي وقت.
- التطبيق **لا يتصل بالإنترنت إطلاقاً** ولا يتطلب أي حساب أو مفتاح API.

## ملاحظات اقتصادية

- سعر الدولار في **الإعدادات ← العملة**؛ كل الأسعار المعروضة والمحسوبة تتبع آخر سعر محفوظ فوراً.
- الهامش والربح محسوبان من **التكلفة بالدولار** × سعر الصرف، فهو متقلب بنفس قوة السعر.
- التوصيات تظهر في شاشة التقارير؛ لكل توصية زر ينقلك لإنشاء كوبون جاهز بنسبة الخصم المقترحة.
